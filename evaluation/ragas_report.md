# RAGAS 평가 결과

추천 시나리오를 실제 서비스로 돌리고, 나온 추천 카드마다 샘플을 만들어 잰다.

| 지표 | 무엇을 보나 | 샘플 |
|---|---|---|
| faithfulness | 후기 3줄 요약의 문장이 검색된 후기에 근거하는가 | 후기 요약 |
| answer_relevancy | 후기 요약이 질문에 맞는 답인가 | 후기 요약 |
| context_recall | 공식 정보(공공데이터)를 검색된 후기가 얼마나 담는가 | 후기 요약 (공공데이터가 있는 카드만) |
| context_precision | 취향 매칭 벡터 검색이 돌려준 문장이 일치도 판단에 쓸모 있고 위에 있는가 | 취향 매칭 |

- 평가 LLM: `us-west-2/us.anthropic.claude-sonnet-4-6` · 임베딩: `amazon.titan-embed-text-v2:0` (ragas 0.4.3)

## 후기 요약 샘플

- 수집일: 2026-11-12 · 채점일: 2026-11-12
- 시나리오: 인-아웃 세트 #1, #2, #3, #4, #8 (실제 서비스로 실행, 후기 요약이 있는 추천 카드 24개 = 샘플 24개)

| 필드 | 내용 |
|---|---|
| question | "{월령} 아기와 '{장소}'에 가려고 해요. 후기를 아기 동반 관점으로 3줄 요약해 주세요." |
| contexts | 후기 요약에 실제로 들어간 네이버 블로그·카페 검색 결과(제목 + 요약문, 최대 10건) |
| answer | 카드에 표시된 후기 3줄 요약 |
| reference | 공공데이터(TourAPI) 편의시설 판정(있음/없음) + 개요 앞 3문장. 카카오에서만 찾은 장소는 공공데이터가 없어 context_recall에서만 빠짐 |

- **faithfulness (목표 달성):** 요약 문장 대부분이 검색된 후기에 근거가 있다. 낮은 샘플은 후기 요약문에 없는 표현(예: '먹이주기 체험')이 한두 개 섞인 경우다.
- **answer_relevancy:** 요약에서 거꾸로 만든 질문과 원래 질문의 임베딩 유사도다. Titan V2는 한국어 문장 유사도가 낮게 압축돼 나온다(같은 Titan으로 잰 기준점: 관련 질문 0.35, 무관한 질문 0.07). 그래서 절대값보다 무관한 질문 대비 차이로 읽어야 한다. 더 나은 다국어 임베딩(Cohere multilingual)은 계정 권한이 없어 쓰지 못했다.
- **context_recall:** 공식 정보(편의시설·장소 개요)를 검색된 후기가 얼마나 담는지다. 후기가 공식 개요(연혁·소개)를 다루지 않으므로 낮은 것이 자연스럽다. 편의시설(주차 등)은 후기에서 자주 확인된다.

## 취향 매칭 샘플

- 수집일: 2026-11-13 · 채점일: 2026-11-13
- 시나리오: #3, #4, #17, #P1, #P2 (#3·#4·#17은 인-아웃 세트, P1·P2는 유사도만으로 정해지는 취향을 보려고 추가한 시나리오. 취향 일치도가 붙은 추천 카드 25개 = 샘플 25개)

| 필드 | 내용 |
|---|---|
| question | "아기와 나들이 갈 곳을 찾고 있어요. 원하는 곳: {취향 문장 또는 '서울숲' 같은 곳}. '{장소}'이(가) 여기에 맞는지 판단할 근거가 되는 장소 정보를 찾아 주세요." |
| contexts | 그 장소의 정보 문장(분류·소개·실내/야외·편의시설·후기 요약) 중 벡터 검색이 돌려준 문장, 유사도 높은 순 (질의 문장마다 상위 2개) |
| answer | 카드에 표시된 취향 일치도 ("'{장소}'의 취향 일치도는 높음입니다.") |

- **context_precision**은 정답 없이(`LLMContextPrecisionWithoutReference`) 검색된 문장 각각이 일치도 판단에 쓸모 있었는지, 쓸모 있는 문장이 위에 있는지를 본다.
- 일치도별 평균: 높음 0.50 (11개) · 보통 0.60 (4개) · 낮음 0.77 (10개)

**해석 (목표 0.7 미달):**
- **'비 와도 괜찮은 곳'(#17)은 검색이 실내 문장을 못 찾는다.** Titan에서 "비 와도 괜찮은 곳"과 "실내 장소입니다"의 유사도는 0.10이라 검색 결과에 실내 문장이 들어오지 않는다. 서비스는 이 경우 일치도를 유사도가 아니라 실내/야외 판정 규칙으로 정하고(`agents/preference.py` `apply_setting`) 카드 근거도 실내 문장으로 바꾸지만, 이 지표는 검색 결과만 보므로 높음 카드가 0점이 된다. 같은 실내 취향이라도 '실내 위주로'(#3)는 1.00이다.
- **비슷한 말을 근거로 인정하지 않는 판정이 있다.** '숲길 산책' 취향에 "나무 그늘이 있는 산책하기 좋은 공원"(성남 중앙공원), '동물 먹이주기 체험'에 "동물원입니다"(서울어린이대공원)가 검색됐는데도 평가 LLM은 숲길·먹이주기라는 말이 직접 없다며 0으로 판정했다.
- **기준 장소(#4 '서울숲 같은 곳')는 질의 문장이 여러 개라 검색 문장이 4~8개로 많다.** 일치도가 낮음인 장소는 관련 없는 문장(편의시설·연령 후기)이 함께 검색돼 0.4 안팎이다.
- 실제 검색이 쓸모 있는 문장을 맨 위에 둔 경우(예: '동물 먹이주기' → 온동물체험농장의 먹이 주기 체험 문장, 0.56)는 1.00이다.
